# REFERENCE ANALYSIS — VISION HITECH Global Website Renewal

Analysed on 2026-09-28 by rendering each site in a headless Chromium (1440px), capturing full-page screenshots and extracting the heading / navigation hierarchy.

Rule applied throughout: **references inform structure, hierarchy and interaction only.** No copy, product claim, statistic, AI capability or visual asset from a reference site is used as VISION HITECH content.

---

## Milesight — https://www.milesight.com/ (MAIN REFERENCE)

Observed structure: Hero carousel with product tabs along the bottom edge → "Our Products" bento (1 large + 2 small + 1 tall card, each with product render on light grey panel) → tabbed use-case explorer (Smart Building / LPR / People Sensing / AI Video) with list-left, image-right → customer-story mosaic (2 large + 2 small) → dark-blue "About" band with stats → news carousel → inquiry form → dense 5-column footer.

**What to Learn:**
- Bento built from a *mix* of card ratios (large / tall / small) where card size follows business priority, not symmetry.
- Product is always physically visible inside the card (render on neutral panel), headline + one line + single CTA.
- Products → use cases → proof → contact is a clear commercial funnel on one page.
- Hero carousel with labelled "tabs" (product name + one-line) doubles as product navigation.
- Tabbed use-case explorer: keeps a lot of solution content in a compact footprint.
- Inquiry form embedded at the bottom of the homepage (not only on /contact).

**What NOT to Copy:**
- Statistics band (partner counts, countries, units deployed) — VISION HITECH has no verified current equivalents; no invented numbers.
- IoT / LoRaWAN / sensor scope — not VISION HITECH's business.
- Customer-story mosaic — VISION HITECH has no published case studies (only history mentions).
- Milesight blue gradient identity, Manrope type, icon set.

## EdgeDX — https://edgedx.ai/ (CONTENT DEPTH REFERENCE)

Observed structure: full-page vertical sections (01–08) — "Edge AI Video Analysis" applied to Security & Surveillance, Construction & Logistics Safety, Store Management, Senior Housing, Public Safety, ITS → "Key Capabilities" list → "System Schematic Diagram" → solution tabs (Hardware / AI Apps / Cloud / Mobile) → app catalogue (each app = name + one-sentence description + licence tier).

**What to Learn:**
- Every application area is presented as a *layered* story: context → capability list → system diagram → related product.
- A "system schematic" graphic is used to explain how devices connect (camera → edge box → VMS → mobile).
- Application pages use a consistent template so depth scales without redesign.
- Capability lists are short, scannable noun phrases.

**What NOT to Copy:**
- **All AI detection functions** (bullying, gun, helmet, tailgating, bear, spill, etc.). None are verified VISION HITECH features.
- "50+ AI apps", LTE/GPS, wide-temperature claims — EdgeDX product facts.
- Full-page scroll-jacking (hurts usability and accessibility on a B2B product site).

Applied to VISION HITECH: Solutions pages follow *Context → Verified capabilities (from existing VISION HITECH technology pages) → Flow diagram → Related VISION HITECH products → Inquiry*. Where VISION HITECH has no official content (AI Vision, Transportation, Vision Marine), the template shows visible "Awaiting official content" slots instead of borrowed claims.

## Hanwha Vision — https://www.hanwhavision.com/global (GLOBAL B2B PRESENTATION REFERENCE)

Observed structure: full-bleed photographic hero (PTZ close-up) with short headline + single CTA → 3-card feature bento (1 large dark with sub-links, 2 stacked) → "Explore Our Products" horizontal carousel with product on light grey tile + model code → deep-navy Industries carousel → Featured News with filter chips → split Support Portal / Contact Sales CTA → 7-column mega footer.

**What to Learn:**
- Scale and restraint: one message per viewport, large type, generous white space.
- Product tiles: model code as the title, product centred on #F2F2F2-like panel — exactly how VISION HITECH's own studio photos are shot (#F1F2F3 background), so they can be presented seamlessly.
- Section rhythm alternates light / dark bands to separate "product" from "industry".
- Support Portal and Contact Sales given equal weight near the footer — strong B2B support accessibility.
- Mega footer mirrors the full IA.

**What NOT to Copy:**
- "Wisenet 9", SoC, AI, cybersecurity claims and Hanwha product names.
- Orange brand colour usage pattern (VISION HITECH's own accent #F47B42 happens to be orange — applied in VISION HITECH's own logo ratio, not Hanwha's large orange blocks).
- Enterprise scale implied by industry list (airports, casinos, banking) — VISION HITECH shows only application areas it has evidence for.

## DEEPX — https://deepx.ai/ (AI / TECHNOLOGY VISUAL EXPRESSION REFERENCE)

Observed structure: dark cinematic hero with product and motion light trails → 4-column benefit cards with small technical pictograms → product-family cards on dark imagery → tabbed success stories → partner logo wall → news grid → award laurels.

**What to Learn:**
- Dark sections with *one* controlled light source make hardware feel precise, not gamer-like.
- Technical copy uses a strong typographic contrast (large statement + small, precise supporting line).
- Motion is reserved for the hero and light "data" accents; the rest of the page is calm.
- Tabbed stories by domain (Edge / Mobility / Factory / City / VMS).

**What NOT to Copy:**
- NPU, TOPS, power-efficiency, "Physical AI", semiconductor claims — none relate to VISION HITECH.
- Partner logo wall and award laurels — no verified VISION HITECH partner list; awards on record are historical (Good Design 2007–2009, export towers 2004/2006) and are shown only in History.
- Heavy blue brand gradients.

Applied to VISION HITECH (Concept B only): dark navy/charcoal base, a single warm accent from the logo, thin "signal" lines that express the Capture → Stream → Record → Monitor path, detection-frame motif derived from VISION HITECH's own ROI / 4K demonstration imagery.

## Bettini Video — https://www.bettinivideo.com/en/ (PRODUCT DISCOVERY + INQUIRY UX REFERENCE)

Observed structure: hero with two entry buttons (overview / product world) → "We meet all your needs" product-family grid (NVR, IP cameras, app, analytics) → "Our added value" service list (consulting, testing, on-site support, repair, service pack) → brand range block with 10-link index → LinkedIn feed → training block → certifications list (ISO 9001, ISO 14001, ONVIF, TAPA) → footer with full contacts.

Top navigation includes a dedicated **Technical Hub**: firmware & software download, technical support, repair & replacement, general catalogue, price list.

**What to Learn:**
- The path *Product → Documentation → Support → Contact* is always one click away.
- Services (repair, RMA, training) are presented as first-class content — reassures B2B buyers before purchase.
- Certifications shown as plain, verifiable statements linked to documents.
- Contact details (address, phone, email) fully visible in footer.

**What NOT to Copy:**
- "Over 20 specialists", "98% satisfaction", "1000 hours of training" — Bettini figures.
- GAMS brand structure, Made-in-Italy messaging, Italian corporate data.
- Cookie/consent heavy UI patterns.

Applied to VISION HITECH: every product card and detail page carries **View Product · Download · Product Inquiry**; the inquiry drawer pre-selects the product; the Support page groups Technical Documents, Download, Warranty (real 27/15/9-month policy), RMA form, Certificates and Tech Support exactly like a "technical hub".
